Shift key test

This page lists exactly what the browser reports for the two Shift keys. Click the page once, then do the four tests below in order, pressing Clear before each one. Take a screenshot of the table after each test.

  1. Press and release both Shift keys together, once.
  2. Hold Left Shift, tap Right Shift once, then release Left Shift.
  3. Hold Right Shift, tap Left Shift once, then release Right Shift.
  4. Hold both, release Left first, wait a second, release Right.
